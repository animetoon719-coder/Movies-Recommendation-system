
# Movie Recommendation System

## Project Overview
This project recommends similar movies based on their genres.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Cosine Similarity
- Google Colab

## Dataset
The project uses the MovieLens dataset containing movie titles, genres, and user ratings.

## How It Works
1. Load the movie dataset.
2. Convert movie genres into numerical features using TF-IDF.
3. Calculate similarity using cosine similarity.
4. Recommend 10 similar movies.

## Example
Input: Toy Story (1995)

Output: A list of similar movies based on genres.

## How to Run
Open the notebook in Google Colab and run the cells in order.
